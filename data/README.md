# Catálogo

Cada aplicativo aprovado é armazenado como um arquivo JSON em `data/apps`.

Os arquivos dessa pasta são a fonte de verdade da galeria. Não edite os totais de curtidas aqui: eles são obtidos das reações 👍 da Issue original durante cada release.

Todo registro precisa apontar para uma Issue real e preservada. A base inicial é descrita em `data/bootstrap/adt-484-493.json` e criada pelo workflow manual **Criar catálogo inicial**, que abre as Issues antes de escrever os arquivos desta pasta.
